Etape 1 - Installation windows 11 sur Vmware Workstation

Important: Il faut avoir au préalablement installer et configurer Vmare Workstation et avoir l'iso windows 11

1. Sur Vmware workstation cliquez sur "create e new virtual machine" et séléctionnez l'option "Typical"
![Capture d'écran 2026-09-15 070247](https://hackmd.io/_uploads/HJfHfdUFGl.png)

![Capture d'écran 2026-09-15 070412](https://hackmd.io/_uploads/BkCUfuIFfe.png)

Etape 2 - Créer plusieurs comptes standards


1. Allez dans les Paramètre puis dans puis dans "Compte" et enfin dans "autres utilisateurs"
![Capture d'écran 2026-09-15 114752](https://hackmd.io/_uploads/SJsFE98FMe.png)

2. Dans les paramètres de "autres utiliseurs" cliquez "ajoutez un compte". Dans la création du compte microsoft si l'utilisateurs ne possèdes pas au préalable un compte microsoft cliquez sur "Je ne dispose pas d'information de connexion de cette personne"
![Capture d'écran 2026-09-15 115007](https://hackmd.io/_uploads/ryqsIqUFMg.png)

3. L'utilisateur peut crée un compte microsoft mais se sera plus de ne pas en crée un, cliquez sur "Ajoutez un utilisateur sans compte microsoft"
![Capture d'écran 2026-09-15 115035](https://hackmd.io/_uploads/rkxnI9IKze.png)

4. Créer le compte selon la personne (nom d'utilisateur, mot de passe et question de sécurité)
![Capture d'écran 2026-09-15 115114](https://hackmd.io/_uploads/Hk42L9LYfg.png)
![Capture d'écran 2026-09-15 115221](https://hackmd.io/_uploads/ryhhUq8Kfx.png)

5. Faite la procédure trois fois pour créer les trois utilisateurs fictif
![Capture d'écran 2026-09-15 115624](https://hackmd.io/_uploads/SkZ6LqLKMe.png)

6. Pour vérifier ou changer l'état des utilisateurs cliquez sur l'utilisateur->changer le type de compte
 ![Capture d'écran 2026-09-15 131154](https://hackmd.io/_uploads/BJoo_oUtze.png)


Etape 3 - Protéger les dossiers personnels avec NTFS

1. Pour vérifier si les comptes sont protégés connectez-vous à l'un des comptes étudiants puis aller dans explorateurs fichiers->ce PC->disque local->utilisateurs puis cliquer sur l'un des autres comptes étudiant un message vous dira que vous ne pouvez pas y accéder
![Capture d'écran 2026-09-15 140123](https://hackmd.io/_uploads/Skg7c2IYzg.png)


Etape 4 - Mise en place une politique de mots de passe

1. Sur le compte administrateurs appuyez sur windows+R et entrez la commande "secpol.msc"
![75557c8f-38fd-4c41-8691-eea14bcdfbc5](https://hackmd.io/_uploads/H179n3IYzx.jpg)

2. Allez ensuite dans "Stratégie de compte"->"Stratégie de mot de passe" ici vous pourrez mettre une politique de mot de passe
![Capture d'écran 2026-09-15 143334](https://hackmd.io/_uploads/SJzF6hUtGg.png)


Etape 5 - Configuration du verrouillage de session

Pour la cette configuration aller dans les Paramètres->Personnalisation -> Écran de verrouillage -> Économiseur d'écran
Cliquez sur "A la reprise, demander l'ouverture de session" et vous pourrez modifier le délai de la mise en veille du pc
![Capture d'écran 2026-09-15 152256](https://hackmd.io/_uploads/S1amvp8Kfg.png)

Etape 6 - Configuration d'un compte administrateur distinc pour la maintenance

1. Allez dans le panneau d'affichage et séléctionez "Modifiez le type de compte"
![Capture d'écran 2026-09-15 155706](https://hackmd.io/_uploads/Bkk4JCUKGl.png)

2. Vous aurez accés ensuite à tout les utilisateurs du PC
![Capture d'écran 2026-09-15 155723](https://hackmd.io/_uploads/rklO1AIFzg.png)

3. Pour modifier le status d'un utilisateur cliquez sur l'utilisateur souhaitez puis sur "modifier le type de compte"
