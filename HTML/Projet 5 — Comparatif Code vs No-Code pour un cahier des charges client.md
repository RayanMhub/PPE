**Etape 4 - recommandation argumentée pour le cas client**
 Tout dépendra de ce que veux faire le clients. Si le clients souhaite une page complete le client devra prendre Code bien que cela lui demandera du temps. Mais si le clients veut faire une page toute simple il peut prendre le No-code, il est facile à utiliser et cela lui prendra peu de temps.
